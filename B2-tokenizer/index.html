Exemple real · projecte extern

Caveman: reduir la verbositat de les respostes

Caveman és una habilitat per a agents de codi que elimina farciment i manté intactes el codi, les ordres i els errors. És una aplicació directa del que acabes de mesurar: una resposta més breu pot utilitzar menys tokens de sortida i ser més ràpida de llegir.

Què no fa: no redueix automàticament els tokens d’entrada ni de raonament. El mateix projecte adverteix que, en tasques ja breus, la instrucció extra pot no compensar. Mesura-ho sempre en el teu cas.

Què és un token i què compta aquesta eina?

Un token és una peça de text que una codificació pot assignar a una paraula sencera, una part de paraula, un signe, un espai o diversos bytes d’un caràcter. Per això les fronteres no coincideixen necessàriament amb les paraules.

Aquesta visualització aplica localment la codificació o200k_base mitjançant gpt-tokenizer (s’obre en una pestanya nova), una implementació compatible amb el tokenitzador obert tiktoken (s’obre en una pestanya nova).

Compta només el text pla. Una petició real pot afegir rols, instruccions, eines, fitxers, imatges i altres elements. Els tokens d’entrada i de sortida també poden tenir preus diferents. Per obtenir el recompte exacte d’una petició completa cal utilitzar el mecanisme de recompte del model corresponent.

Dependència i nota tècnica revisades el juliol de 2026. Les famílies de models i les seves codificacions poden canviar amb el temps.
