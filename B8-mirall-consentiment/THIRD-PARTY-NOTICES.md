# Avisos de tercers

## Runtime de producció

El widget no incorpora biblioteques, tipografies, imatges, analítica ni
recursos de tercers. Utilitza només API web del navegador i fitxers locals del
projecte.

`content.js` conté enllaços a fonts oficials. Són referències que la persona
pot obrir; no es carreguen automàticament ni formen part del runtime.

## Eines de desenvolupament

Les eines següents només s’utilitzen per formatar i provar:

- Playwright Test, Apache-2.0;
- axe-core i la integració per Playwright, MPL-2.0;
- Prettier, MIT.

Consulta `package-lock.json` per versions i dependències transitives exactes.
Aquestes eines no es distribueixen a l’alumnat quan es publiquen només els cinc
fitxers de producció indicats a `README.md`.
