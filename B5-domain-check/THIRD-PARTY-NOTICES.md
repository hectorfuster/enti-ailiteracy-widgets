# Third-party notices

The production artifact uses no third-party runtime code, fonts, images, or
network services. It relies on the learner's system font stack.

The development-only test toolchain is not embedded in `index.html`:

- Playwright Test — Apache License 2.0
- axe-core and `@axe-core/playwright` — Mozilla Public License 2.0
- Prettier — MIT License

The activity links to authoritative external sources only after a learner
submits a judgment. Opening those links is optional and occurs in a new tab.
Source titles and publishers are factual citations, not bundled third-party
content.
